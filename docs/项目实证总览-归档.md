## Reflect 铁律
- `callByName`/`findMethod` **只查精确类 declaredMethods**；目标在父类/接口实现类一律 `callDeep`，否则恒 null 且零报错
- 重载多**不要用 `findMethod(name, N)`**，用 `findMethodByShape`；expect 传 null = 该位任意 = 丢约束
- 宿主可能返回 unmodifiable 集合 ⇒ 过滤一律新建集合
- **跨 ClassLoader 匹配参数类型只能比 `parameterTypes[i].name` 字符串**（模块自带 androidx，同名类是两个 Class 对象 ⇒ 恒不等、钩子静默不装）；`android.*` boot 类不受影响
- **`Chain#proceed(args)` 参数个数必须与目标方法完全一致**：`getArgs()` 不可变 ⇒ `toTypedArray()` 复制后整体传回。一段钩子覆盖多个重载时用 `proceedReplacingFirst` 式写法
- **`proceed()` 无参 = 用原参数**（API 102 独立重载）
- **hook 目标若为 private 方法，先 `method.isAccessible = true` 再 hook**
- 返回类型必须严格匹配：DTO getter 常见装箱（`getIsVip()Ljava/lang/Integer;`），给 Boolean 会 CCE；宁可不挂也别给错类型
